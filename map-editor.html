HOW TO COLLABORATE

This map editor runs in your browser. Drag markers to position them on the map, then export your changes.

TO SUBMIT YOUR EDITS:

  1. Position markers by dragging them on the map
  2. Click EXPORT to download your changes as a single file
  3. Email the file to seeyouinfreeiran@gmail.com

SAVING LOCALLY (OPTIONAL):

If you have the project files on your computer, use LOAD ALL to open the data folder, then SAVE ALL to write changes directly.

TIPS:

  1. Use Ctrl/Cmd+S as a shortcut to save
  2. Scroll wheel to zoom, drag to pan the map
  3. Include a note in your email describing what you changed
